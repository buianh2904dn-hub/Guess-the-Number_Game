# 🔢 Number Guessing Game

A simple, interactive terminal game written in Python where players test their intuition by guessing a randomly generated number.

#### ✨ Key Features
* **Limited Attempts:** Players get up to 3 tries to guess the correct number.
* **Helpful Hints:** The game guides you with feedback if your guess is too high or too low.
* **Replay Option:** Easily play multiple rounds by typing `Y` or `YES` when prompted.
